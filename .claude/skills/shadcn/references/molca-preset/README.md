# Molca shadcn preset

A concrete shadcn theme + extended Button that make shadcn output match the
**Molca — Shadcn Design System** Figma (file `mvVIgPwuzefi1XA90TstQ6`). Use this
when building **new shadcn surfaces** for Molca.

> See the `molca-local` note in the parent [SKILL.md](../../SKILL.md).

## Files

| File | What it is |
|------|------------|
| [`globals.css`](globals.css) | full foundation theme — semantic colors (**Light + Dark**), radius scale, type scale, fonts (Tailwind v4 `@theme`) |
| [`button.tsx`](button.tsx) | Button with Molca size scale (`xs`–`xl`) + variant→`Type` mapping + selected/focused states |
| [`patterns.tsx`](patterns.tsx) | 9 button patterns: group, segmented, vertical, split, input-search, input-group, dropdown-menu, currency select, agent popover |

> ✅ Theme tokens (both modes), the Button, and all 9 button **patterns** are
> **sourced from Figma** via the plugin bridge.

## Token provenance

Every value in `globals.css` is read from Figma via the plugin bridge, alias-resolved,
and annotated with its source: semantic **colors** from the "Tokens" collection (Light
Mode / Dark Mode), the **radius** scale from Primitives, and the **type** scale + fonts
from Typography. Notable: **the brand flips to lime (`#cfff33`) in dark mode**, and
buttons are plain 12px-radius rectangles (no scallop). Full foundation docs:
[colors](../../../../designer/design-system/references/foundations/colors.md) ·
[typography](../../../../designer/design-system/references/foundations/typography.md) ·
[spacing & radius](../../../../designer/design-system/references/foundations/spacing-radius.md).

## How to apply

### Option A — install via the Molca shadcn registry (recommended)

These files are also published as a shadcn **registry** at the repo root
([`registry.json`](../../../../registry.json), 4 items: `molca-base`, `molca-theme`,
`button`, `button-patterns`; validated with `shadcn registry validate`). Once the repo
is **public**, consume it by GitHub address:

```bash
# one-shot foundation (theme + button):
npx shadcn@latest add molca-id/skills/molca-base

# or individually:
npx shadcn@latest add molca-id/skills/molca-theme      # full token set (light+dark)
npx shadcn@latest add molca-id/skills/button
npx shadcn@latest add molca-id/skills/button-patterns
```

> **While the repo is private**, GitHub-address install won't resolve (shadcn GitHub
> registries are public-only). Until then: clone/skills-install the repo, then
> `npx shadcn@latest build` locally and `add ./public/r/molca-theme.json`, or host the
> built `public/r/*.json` on an internal URL and configure it as the `@molca` registry
> in `components.json`. Or use Option B below.

### Option B — apply the files directly (no registry)

1. Merge `globals.css` variables into the project's `tailwindCssFile`
   (find it via `npx shadcn@latest info --json`). **Don't** create a new CSS file.
2. Add Poppins (e.g. `next/font` or an `@import`) and confirm `--font-sans` resolves.
3. Replace `components/ui/button.tsx` with `button.tsx`, fixing the `@/lib/utils`
   import to the project's alias.

### Option B — capture as a real shadcn preset code

shadcn preset codes (e.g. `a2r6bw`) are **generated by the theme builder**, not
hand-authored. To mint one for Molca:

1. Open the theme builder at <https://ui.shadcn.com>, enter the `globals.css`
   values above, and copy the generated preset code.
2. Apply it: `npx shadcn@latest apply <code>` (existing project) or
   `npx shadcn@latest init --preset <code>` (new project).
3. Record the code here so the team reuses it instead of re-entering values.

> Tailwind v3 projects: convert the `:root` colors to HSL channel triplets
> (`--primary: 0 4% 13%;`) and drop the `@theme inline` block — put the scale in
> `tailwind.config`. shadcn's `customization.md` covers both versions.
